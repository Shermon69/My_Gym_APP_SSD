=== V6 - Password Hash Exposure - BEFORE evidence ===

Baseline commit: 6c86dd2

--- 1. Unauthenticated password hash exposure ---

Request:
GET /api/users

No authentication token was supplied.

Observed result:
The endpoint returned user records without requiring authentication.
The response included a password field containing bcrypt password hashes.

Example:
password: [REDACTED]

Result:
An unauthenticated request to /api/users exposed stored password hashes.
This demonstrates the V6 password hash exposure vulnerability.

--- 2. Safety and credential handling ---

The test was performed against the local development environment.

Actual password hashes were not included in this evidence file.
